### 🔍 NHÓM: Thuật toán Tìm kiếm (Searching Algorithms)

| Thuật toán | Cấu trúc dữ liệu | Độ phức tạp TB | Độ phức tạp Tệ nhất |
| :--- | :--- | :---: | :---: |
| **Linear Search** | Mảng bất kỳ | $\mathcal{O}(n)$ | $\mathcal{O}(n)$ |
| **Binary Search** | Mảng đã sắp xếp | $\mathcal{O}(\log n)$ | $\mathcal{O}(\log n)$ |
| **Interpolation Search** | Mảng phân bố đều | $\mathcal{O}(\log \log n)$ | $\mathcal{O}(n)$ |
| **BST Search** | Cây BST / Red-Black Tree | $\mathcal{O}(\log n)$ | $\mathcal{O}(n)$ |
| **Hash Search** | Hash Table (`unordered_map`) | $\mathcal{O}(1)$ | $\mathcal{O}(n)$ |
